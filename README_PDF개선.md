# PDF 리포트 개선 안내

기준: `SolarPowerGeneration_vworld.zip` (브이월드 주소 연동 버전)

## 1. 적용 방식

기존 HTML → html2canvas → jsPDF 방식을 유지하되 보고서 전용 HTML/CSS를 A4 두 페이지로 재설계했습니다. 별도의 Word 변환 서버나 신규 npm 의존성이 필요하지 않습니다. PDF 내보내기 버튼은 기존 위치와 동작 그대로입니다. PDF는 이미지 기반으로 저장되어 본문 텍스트 검색·선택은 지원하지 않습니다.

- 1쪽: 초기 투자비, 20년 누적 수익, 투자비 회수 시점, 설치·발전 조건 및 투자·금융 조건, 누적 수익 및 연간 수익 그래프
- 2쪽: 1~20년차의 발전 수익, 운영 비용, 대출 원리금, 당해 수익, 누적 수익 및 합계, 산출 기준·유의사항
- 그래프는 PDF 전용 SVG로 구현해 차트 애니메이션의 영향을 받지 않습니다. 음수 수익도 축 범위에 포함합니다.
- 현재 시뮬레이터에서 실제 사용하는 입력값을 보고서에 전달합니다. 기존 계산식·지도 기능은 수정하지 않았습니다.
- PDF 생성 중 입력값을 변경하더라도 두 페이지는 내보내기 버튼을 누른 시점의 동일한 결과를 사용합니다.
- PDF 캡처 전용 영역은 화면에 노출되지 않으며, A4 비율에 맞춰 3배 해상도로 저장합니다.

## 2. 실행 및 배포

기존 프로젝트와 같은 방법으로 실행합니다. Node.js는 Vite 8이 지원하는 버전(예: Node 22.12 이상)을 사용하세요.

```powershell
pnpm install --no-frozen-lockfile
pnpm dev
```

브라우저에서 시뮬레이터를 열고 `PDF 리포트 다운로드` 버튼을 클릭합니다.

브이월드 인증키 환경변수는 기존 설정을 유지합니다. 이미 운영 중인 프로젝트에 반영하려면 아래 변경 파일만 덮어써도 됩니다. `package.json`, `pnpm-lock.yaml`, Vercel 환경변수는 변경하지 않아도 됩니다.

```text
src/App.jsx
src/components/ChartView.jsx
src/components/PdfReportTemplate.jsx
src/components/PdfReportTemplate.css
src/utils/pdfExporter.js
src/utils/reportData.js
tests/report-data.test.js
```

배포 전 `pnpm test`, `pnpm build` 실행 후 PDF 다운로드를 확인하세요.

## 3. 유의사항

- 누적 수익은 기존 코드에서 계산한 연간 수익의 합계이며 초기 투자비를 별도로 표시합니다. 투자비 회수 시점 역시 기존 계산식에 따릅니다.
- 기존 `App.jsx`의 초기 투자비 산식은 설비 추정비 + 부지매입비이며 기타 비용(`additionalExpense`)은 미반영 상태입니다. 이번 작업은 PDF 출력 개선이므로 계산식을 변경하지 않고 보고서에 미반영 상태를 명시했습니다.
- 차트 단위는 만원, 연도별 손익표 단위는 원입니다. 금액은 표에서 원 단위 반올림하여 표시합니다.
- PDF 디자인은 로컬 Chromium에서 원본 프로젝트에 포함된 React, html2canvas, jsPDF로 보고서를 렌더링하고 실제 다운로드한 두 페이지를 확인했습니다. 기본값 및 손실 시나리오를 별도로 검증했습니다. 네트워크 제한으로 Vite 전체 의존성 설치 및 전체 앱 빌드는 이 작업 환경에서 수행하지 못했습니다. Vercel 배포와 실주소 검색은 기존 환경에서 확인하세요.
